# 📊 Benchmark Outputs and Artifacts

This directory stores outputs generated by `scripts/evaluate.py` and the Streamlit Evaluation Lab:

- `evaluation_results.csv`: Detailed per-image quantitative records (PSNR, SSIM, Latency, Dimensions).
- `evaluation_summary.md`: Formatted Markdown report with aggregate statistics and methodology notes.
- `benchmark_comparison_chart.png`: Publication-grade visualization comparing Bicubic baseline vs. ESRGAN.
- `benchmark_visuals/`: (Optional) Reconstructed LR, Bicubic, ESRGAN, and HR image pairs.
